# MG伴走サポート — コーディング軸（ヒアリング記録用）

ヒアリングを「生徒の背景」ではなく **MGが何をしたか** で統一記録するための軸。
報告・分析は必ずこの7項目で Yes/No + 具体例 を埋める。

| コード | 着眼点 | 記録する内容（例） |
|--------|--------|-------------------|
| **A** | コミット設計 | 次回まで/月末までに「何本・何を」やるか数値で宣言させ、次セッションで確認した |
| **B** | 実行スケジュール設計 | 撮影・編集・投稿の日時を一緒にカレンダー化（何回目まで継続したか） |
| **C** | 時間・優先順位設計 | 可処分時間の洗い出し、他タスクとの優先順位・時間配分を整理した |
| **D** | 停滞解除 | 迷い・不動の理由をコーチングし、次の1アクションに落とした |
| **E** | 講師連携 | 品質・収益化・添削のため講師1on1/添削ルートを設計・手配した |
| **F** | ペース調整 | 伸び悪化・体調悪化時に数より質へ切替、ペースダウンを合意した |
| **G** | 初回動機の言語化 | 入会動機を具体的ゴール（投稿頻度・収益化等）に落として合意した |

## 記録しないもの（別欄）

- 生徒の性格・ライフイベント → `生徒要因` 欄
- 講師側の問題 → `外部要因` 欄
- MGサポート以外の自走 → `生徒自走` 欄

## 判定

- **◎** = 継続的・明示的に実施（複数セッション or 中核施策）
- **○** = 部分的・一時的に実施
- **—** = ヒアリング上、実施記載なし
- **?** = ヒアリング情報不足
