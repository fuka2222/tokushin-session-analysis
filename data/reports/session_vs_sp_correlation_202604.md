## 結論サマリー

| 観点 | 見えていること |
|------|---------------|
| **自己分析の早さ → STEP** | **最もはっきり**。SA gap 7日以内はSTEP中央値15。15日超8名は全員SP未完了（うち5名は50日SP） |
| **SA → 初回伴走の間隔** | 中央値**11日**。自己分析後7日以内に伴走開始は**18%**のみ |
| **伴走の回数** | STEPと連動（r=0.50）するが、**SPを早く終わらせる効果は弱い** |
| **週次ペース** | STEPと r=0.56 だが、**単独の警戒指標には不向き**（週次が悪くてもSTEP19の人あり） |
| **伴走の役割** | SPの「加速器」より、**並行・継続サポート**。効くのは**いつ始めたか** |

**運用で最優先**: SP開始〜**1週間以内の自己分析** → できれば**自己分析後1〜2週間以内に伴走**。

## 定義

| 用語 | 定義 |
|------|------|
| **SP開始日** | Lステップ「入会フォーム回答日」+ 3日 |
| **SA gap** | 自己分析セッション実施日 − SP開始日（日数）。小さい＝早い |
| **自己分析（SA）** | コミットプラン V列 |
| **コーチング（伴走）** | コミットプラン W列以降（0回目〜）。セルに日付がある回数をカウント |
| **SP完了日数** | SP開始から SP（STEP19）完了までの日数。未完了は集計から除外することがある |
| **STEP進捗** | Lステップ STEP1〜19 の最終完了STEP（0＝未着手） |
| **STEP中央値** | そのグループの生徒のSTEPを並べたときの**真ん中の値** |
| **週次率** | 隣接する伴走セッション間隔が5〜9日だった割合（2回未満は判定不可） |
| **50日SP** | スタータープログラム50日版。**STEP比較・遅延分析から除外**する5名（下記） |

**SA gap の例**
- SP開始 4/4、自己分析 4/5 → **SA gap = 1日**
- SP開始 4/4、自己分析 4/24 → **SA gap = 20日**

**50日SP除外（30日SPコホートと混在しないよう）**: あさのえりか / あらきりえこ / あわやしょうま / ふっくみな / しまおかみさと

## 4. 相関係数（n=38）

**r** = −1〜+1。2つの指標が同じ方向に動きやすいかの目安（**因果ではない**）。

| 変数 | 意味 |
|------|------|
| **STEP** | Lステップの最終完了STEP |
| **SA gap** | 自己分析までの日数（大きい＝遅い） |
| **週次率** | 伴走間隔が5〜9日の割合 |
| **コーチング回数** | コミットプランに記載された伴走回数 |
| **SP完了日数** | SP開始からSP完了までの日数 |

| 変数ペア | r | n | ざっくり解釈 |
|---------|---|---|-------------|
| STEP vs **SA gap** | **−0.76** | 38 | 自己分析が遅いほどSTEPが低い（強い） |
| STEP vs **週次率** | +0.56 | 36 | 週次が良いほどSTEPが高い傾向（例外あり§2） |
| STEP vs コーチング回数 | +0.50 | 38 | 進んでいるほど回数も多い |
| STEP vs 初回伴走（SPから） | −0.27 | 36 | 伴走開始が遅いほどSTEPが低い傾向 |
| STEP vs SA→伴走間隔 | −0.29 | 33 | 自己分析後の伴走が遅いほどSTEPが低い傾向 |
| **SP完了日数** vs SA gap | **−0.13** | 27 | **SPを何日で終えるか**はSA gapとほぼ無関係 |
| SP完了日数 vs コーチング回数 | +0.25 | 27 | 弱い |
| SP完了日数 vs 週次率 | +0.07 | 26 | ほぼ無相関 |

## 5. 伴走セッションはSPを加速させるか？

| 問い | 答え |
|------|------|
| 伴走でSPが早く終わる？ | **効果は弱い**（SP完了日数 vs SA gap r=−0.13） |
| 伴走回数とSTEPは？ | 連動（r=0.50）するが **進んでいるから回る** 可能性大 |
| 何が効く？ | **SA gap（§1）** と **SA→伴走の間隔（§3）** |

### SP期間中の伴走密度 vs SP完了

| SP期間中の伴走 | 人数 | STEP中央値 | SP完了まで |
|---------------|------|-----------|-----------|
| 0回 | 1名 | 9 | 15日 |
| 1〜2回 | 15名 | 13 | 29日 |
| 3回以上 | 12名 | 15 | 29.5日 |

SA gap 7日以内に絞っても **約29日で完了** — 期間中の回数だけではSP完了速度は変わらない。

### 週次ペース vs SP完了速度

| 週次ペース | SP完了中央値 | STEP中央値 |
|-----------|-------------|-----------|
| 週次率 80%以上 | 30日 | 14 |
| 週次率 50%未満 | 29日 | 13 |

→ 毎週ペースを守っているかは、**SP完了速度にはほとんど効かない**。

**総合**: 伴走は「SPを短く終わらせる加速器」より、**SPと並行・その後の継続サポート**。SP進捗を早めたいなら **自己分析をSP開始1週間以内** がデータ上いちばんはっきり効いている。

## 6. 運用上の示唆

1. **SP開始〜7日以内の自己分析** — 38名中66%達成。未達の15日超はフォロー最優先（30日SPは5名・§1表）
2. **自己分析後〜伴走までの空き** — 中央値11日。7日以内に伴走は18% → **短縮が次のKPI**
3. **伴走の回数より開始タイミング** — 早い自己分析 × 早い伴走でSTEP中央値16（§3）
4. **週次ペース単独の警戒は不可** — こいでるか・いのうえなおこは誤検知。`SA gap 14日超 & STEP5未満` を併用
5. **50日SP生徒はSTEP比較から除外** — プログラムが異なる
