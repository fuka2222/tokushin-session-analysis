# ダッシュボード設計（v2）

## 目的

MG・運営が**誰に・なぜ・どう介入するか**を一瞬で判断する。

文字起こしの自動取得は別エンジニア担当。本システムは**評価結果・ロスター・MG入力・進捗CSV**を統合する。

## データソース

| ソース | 内容 | 入力者 |
|--------|------|--------|
| `roster_paste.tsv` | 生徒・MG・SP開始・セッション予定 | スプシから貼付 |
| `student_profiles.csv` | 可処分時間・9マス・MGサポート・属性 | **MG** |
| `session_analysis.db` | 構成遵守・ヒアリング（文字起こし分析） | 自動 |
| `student_progress.csv`（任意） | 投稿数・ステップ・初投稿日 | スプシ連携 |

## 画面で見る指標

### 1. 初投稿30日（SP開始から）

- `done` / `in_progress` / `at_risk` / `overdue`
- 残り日数・SP+何日目で投稿したか

### 2. 可処分時間 × 進捗（4象限）

| 象限 | 意味 |
|------|------|
| 時間多×進捗多 | 理想に近い |
| 時間多×進捗少 | **要深掘り**（仮説リスト表示） |
| 時間少×進捗多 | 効率型 |
| 時間少×進捗少 | 時間確保が課題 |

MG入力: `disposable_hours_week`, `time_used_hours_week`（週あたり時間）

### 3. 9マス（コーチャブル度 × 目標設定度）

MG入力または将来は文字起こしプロンプトで推定:

- `coachable_level`: 高/中/低
- `goal_level`: 高/中/低

→ ①〜⑨のラベルと**次のセッション方針**を表示

### 4. MGが主体的に行ったサポート

`mg_support_notes`（自由記述・MGが更新）

### 5. 属性

年齢・職業・動画経験・PC有無・ジャンル（プロファイルCSV or ヒアリング抽出）

### 6. 注力フラグ（自動）

- 初投稿30日アラート
- 時間多×進捗少
- 9マス⑥⑧⑨
- 分析未実施
- MG記入待ち
